# هریس‌گرد — پروژه اندروید

این پروژه فایل وب‌اپ هریس‌گرد را درون برنامهٔ Android WebView قرار می‌دهد. صفحهٔ اصلی از داخل APK باز می‌شود و برای باز شدن اولیه به اینترنت نیاز ندارد؛ اما تصاویر Unsplash و پیوندهای نقشه در فایل فعلی اینترنت می‌خواهند. پاسخ‌های گفت‌وگوی هریس‌گرد در این نسخه محلی/قاعده‌محور هستند و مدل زبانی مولد نیستند.

## ساخت APK آزمایشی از طریق GitHub (بدون رایانه)
1. فایل ZIP پروژه را در گوشی دانلود و استخراج کنید.
2. در GitHub یک مخزن جدید با نام `harisgard-android` بسازید.
3. محتویات پوشهٔ `HarisgardAndroid` را در ریشهٔ مخزن آپلود کنید؛ خود پوشه را به‌عنوان یک زیرپوشهٔ اضافه آپلود نکنید.
4. وارد تب **Actions** شوید و گردش‌کار **Build Harisgard APK** را اجرا کنید؛ یا یک commit روی شاخهٔ `main` انجام دهید.
5. بعد از سبز شدن کار، از همان اجرای workflow قسمت **Artifacts** فایل `Harisgard-debug-apk` را دانلود کنید.
6. ZIP خروجی را استخراج و `app-debug.apk` را روی گوشی نصب کنید. این فقط نسخهٔ آزمایشی است.

## پیش از ارسال به مایکت
- APK نهایی باید با کلید انتشار اختصاصی امضا شود؛ APK آزمایشی برای انتشار فروشگاهی مناسب نیست.
- نام، آیکون، اسکرین‌شات‌ها، توضیحات، رده‌بندی سنی و سیاست حریم خصوصی را آماده کنید.
- همهٔ صفحات، دکمه‌ها، لینک‌ها و عملکرد آفلاین را روی چند دستگاه آزمایش کنید.
- فایل فعلی از تصاویر خارجی استفاده می‌کند؛ در اولین بار نمایش تصاویر اینترنت لازم است. اگر ادعای «کاملاً آفلاین» می‌کنید باید این تصاویر را نیز محلی کنید یا متن ادعا را اصلاح کنید.
- هیچ تضمینی برای تأیید فروشگاه وجود ندارد؛ پذیرش نهایی بر اساس بررسی روز فروشگاه است.
